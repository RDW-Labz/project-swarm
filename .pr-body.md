- #170: the git guard also refuses `git checkout -- <path>` / `git checkout <path>` / `git restore <path>` when that path has uncommitted changes, printing "commit WIP first"; a plain branch checkout or a clean path still passes through, and a global `-C` is honored by the check itself. Shell and codex job boilerplate now says to run mutants with `swarm mutants`, never by hand.
- #171: `swarm mutants` accepts `id` as an alias for `name` in a mutants file (renamed with a warning), and `env --print` now states the exact mutants file shape, byte-identical to a job's own mutantsFile preamble.
- #172: the pre-push `uv-lock-check` resolves `uv` like every other toolchain binary (toolchains dir, then PATH) before ever spawning it; a lock check that cannot even start now refuses `lock-check-cannot-run: uv not found (tried …)` instead of an empty reason.
- #174: `ship --require-section 'Mutation check'` no longer refuses a PR body whose heading is `## Mutation check (mutant → killing test)` — a required section now matches `## <name>` followed by end of line, a space, or `(` (a boundary-prefix match, so `## Mutation checks` still does not match); a genuinely missing section's refusal now names the nearest heading actually found in the body.
- #175: `ship --check '["uv",...]'` no longer gives a bare `spawn-error` with no program or PATH shown when run from a shell without the toolchains dir on PATH. Ship/run checks resolve a bare check `argv[0]` through the same resolver #172 added (now exported as `resolveToolchainBin`) before ever spawning it; one that cannot be resolved refuses just that check with `cannot-run: <prog> not found (tried <dirs>)`.
- #176: `ask`'s own prompt now tells the worker that any claim in its answer that something is missing, never called, omitted, or absent must carry `"basis":"context-only"` and name what it searched. The `ask` result gains `contextFiles` (the exact context given) and a `warnings` array that gains `absence-claim-limited-context` whenever the worker's own answer text contains such a claim (a simple, case-insensitive, whole-word scan), independent of whether the worker added the basis marker. New exported `hasAbsenceClaim`.
