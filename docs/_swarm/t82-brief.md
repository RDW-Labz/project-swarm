2. Lesson 325 — output cap for single-request agents. In `validate` (and therefore `run`, which validates first): for a job whose agent is `openrouter` or `api` (any model), sum the byte size of each declared output that already exists under the root; refuse with code `output-cap-exceeded` when the total exceeds `outputCapBytes.total` (default 61440) or any single existing output exceeds `outputCapBytes.perFile` (default 15360). The message lists each offending file with its size and ends with: "route this job to agent codex (edits in place) or split the outputs". Per-job override `outputCapBytes: { total, perFile }` (integers > 0, else `invalid-output-cap`); config override `outputCap: { total, perFile }` in the swarm config read by `tools/local-config.mjs` (read it; do not add a new config file). Jobs on agent `claude`, `codex`, `claude-shell` (any shell job) are never checked. Non-existent outputs count 0 bytes.
